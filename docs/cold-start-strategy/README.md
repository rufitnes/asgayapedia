**How to bootstrap the network from zero to sustainable growth**

---

## 🚧 Under Construction — Contributors Welcome!

This section is being actively developed. We're documenting Asgaya's cold-start strategy: how to launch a permissionless P2P remittance network from zero users to sustainable organic growth.

**Why this matters:**
- No liquidity = no network (chicken-and-egg problem)
- Payment method diversity requires pioneer testing
- Geographic expansion needs prioritization strategy
- Phase 0 → Phase 1 transition criteria must be clear

**What needs documentation:**

### 1. Phase 0 Approach
**Topic:** Trusted participant testing, Spain focus, initial validation  
**Key questions:**
- Who are the Phase 0 participants?
- What metrics define "ready for Phase 1"?
- How do we maintain permissionlessness while starting small?

### 2. Payment Method Rollout
**Topic:** Progressive payment expansion via pioneer program  
**Key questions:**
- How do pioneers test and document new payment methods?
- What evidence standards for fraud protection?
- When is a payment method "production-ready"?

### 3. Pioneer Program
**Topic:** Incentivizing early adopters and documentation contributors  
**Key questions:**
- What rewards for pioneers? (badges, fee discounts, reputation?)
- How do we verify pioneer contributions?
- What prevents Sybil attacks on pioneer benefits?

### 4. Corridor Expansion
**Topic:** Geographic prioritization strategy  
**Key questions:**
- Which corridors after Spain → Venezuela?
- What signals indicate corridor readiness?
- How do we balance demand vs. regulatory risk?
