==============================================
1. RATE APIs
==============================================

GET /rates/current
Get current exchange rates for covenant creation

Query: from_currency=EUR, to_currency=VES, amount=100

Response 200:
{
  "rates": {"EUR_BCH": 0.001, "EUR_VES": 42.5, "BCH_VES": 42500},
  "amounts": {"sender_pays_eur": 101, "recipient_gets_ves": 4250, "collateral_bch": 0.107},
  "fees": {"seller_fee_eur": 0.5, "merchant_fee_eur": 0.5, "protocol_fee_eur": 0},
  "timestamp": "2026-05-12T14:30:00Z",
  "valid_for_seconds": 300
}

Errors: 429 Rate limit | 503 API unavailable

---

GET /rates/historical?covenant_id=abc123
Get promise rate vs execution rate for covenant

Response 200:
{
  "promise_rate": {"EUR_BCH": 0.001, "timestamp": "2026-05-12T10:00:00Z"},
  "execution_rate": {"EUR_BCH": 0.00098, "timestamp": "2026-05-12T14:30:00Z"},
  "variance_pct": -2.0
}

==============================================
2. COVENANT APIs
==============================================

POST /covenants/create
Create new covenant request (sender initiates)

Request:
{
  "recipient_phone": "+58 412 1234567",
  "amount_eur": 100,
  "destination_currency": "VES",
  "merchant_id": "merchant_001" (optional),
  "rate_lock_token": "rate_abc123"
}

Response 201:
{
  "covenant_id": "cov_abc123",
  "bounty_code": "7392",
  "status": "PENDING_BIZUM",
  "bch_seller": {
    "bizum_phone": "+34 600 123 456",
    "amount_to_send": 101,
    "concept_field": "+58 412 1234567"
  },
  "expires_at": "2026-05-12T14:35:00Z"
}

Errors: 400 Invalid phone | 422 Rate lock expired | 503 No BCH sellers

---

GET /covenants/:covenant_id
Get covenant status and details

Response 200:
{
  "covenant_id": "cov_abc123",
  "bounty_code": "7392",
  "status": "ACTIVE",
  "amounts": {"sender_paid_eur": 101, "recipient_gets_ves": 4250, "collateral_bch": 0.107},
  "parties": {"sender_id": "user_001", "recipient_phone": "+58 412 1234567"},
  "timeline": {"created_at": "...", "activated_at": "...", "expires_at": "..."},
  "covenant_address": "bitcoincash:pqr...xyz"
}

Status values: PENDING_BIZUM | AWAITING_PAYMENT | ACTIVE | EXECUTING | COMPLETED |
               TIMEOUT_REFUND | MARGIN_CALL | MARGIN_REFUND | CANCELLED

---

POST /covenants/:covenant_id/sign
Sign covenant (merchant + recipient both required)

Request:
{
  "signature": "0xabc...",
  "signer_role": "merchant",        // "merchant" or "recipient"
  "timestamp": "2026-05-12T14:30:00Z"
}

Response 200:
{
  "signatures_received": ["merchant", "recipient"],
  "status": "EXECUTING",
  "estimated_completion": "2026-05-12T14:31:00Z"
}

Errors: 403 Unauthorized signer | 409 Already executed/expired | 422 Invalid signature

---

POST /covenants/:covenant_id/margin-call-response
BCH seller responds to margin call

Request:
{
  "action": "add_bch",              // "add_bch" or "let_refund"
  "additional_bch": 0.010
}

Response 200:
{
  "status": "ACTIVE",
  "new_collateral_bch": 0.117,
  "margin_call_resolved": true
}

---

POST /covenants/:covenant_id/cancel
Cancel covenant (sender, within 5-min Bizum window)

Response 200: {"status": "CANCELLED", "refund": "Split refund processed"}
Errors: 403 Not sender | 409 Cannot cancel (window expired)

==============================================

400 BAD REQUEST:
{"error": "invalid_request", "message": "Invalid phone number format", "details": {...}}

401 UNAUTHORIZED:
{"error": "unauthorized", "message": "Missing or invalid access token"}

403 FORBIDDEN:
{"error": "forbidden", "message": "Not authorized for this action"}

404 NOT FOUND:
{"error": "not_found", "message": "Covenant not found", "covenant_id": "cov_xyz789"}

409 CONFLICT:
{"error": "conflict", "message": "Covenant already executed", "current_status": "COMPLETED"}

422 UNPROCESSABLE:
{"error": "validation_failed", "message": "Rate lock expired", "details": "..."}

429 RATE LIMIT:
{"error": "rate_limit_exceeded", "message": "100 req/min limit", "retry_after_seconds": 60}

500 INTERNAL ERROR:
{"error": "internal_error", "message": "Unexpected error", "request_id": "req_abc123"}

503 UNAVAILABLE:
{"error": "service_unavailable", "message": "CoinGecko API down", "retry_after_seconds": 30}

==============================================
DATABASE MODELS
==============================================

covenants: covenant_id, bounty_code, sender_id, recipient_phone, merchant_id, bch_seller_id,
  amount_eur, collateral_bch, status, covenant_address, timestamps, rates
users: user_id, phone, role, country, bch_address
merchants: merchant_id, user_id, name, location (lat/lon), address, available_cash_ves, active
signatures: signature_id, covenant_id, signer_role, signature, signed_at
notifications: notification_id, user_id, type, message, sent_at, read_at

==============================================
BACKEND TECH STACK
==============================================

- Runtime: Node.js 20 + Express
- Database: PostgreSQL 16
- Cache: Redis 7 (rate limiting, sessions)
- BCH: Bitcoin Cash Node (full node)
- Queue: Bull (Redis-based job queue)
- External APIs: CoinGecko (BCH/EUR), DolarAPI (EUR/VES blue dollar)
- SMS: Twilio (recipient notifications)
- Push: Firebase Cloud Messaging
- Monitoring: Sentry (errors), Prometheus (metrics)

==============================================
EDGE CASE HANDLING
==============================================

TIMEOUT (24h): Cron checks expired covenants → Split refund → Status: TIMEOUT_REFUND
MARGIN CALL (BCH >7% drop): Monitor price every 30s → SMS seller (60 min response) → Add BCH or refund
DUPLICATE CLAIM: Check status before lookup → Return 409 if COMPLETED → Transaction locks prevent double-spend

==============================================
PHASE 0 MONITORING
==============================================

Metrics: Covenant rate, execution %, time-to-claim, margin calls, API latency, errors, inventory
Alerts: Margin calls >15%, Timeouts >10%, API downtime >5min, SMS failures >5%, Query time >1s
