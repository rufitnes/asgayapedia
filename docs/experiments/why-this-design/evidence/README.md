## Key Research

### 1. Remittance Market ($589B Global)
**Source:** World Bank Remittance Prices Database  
**Finding:** Average 5-8% fees, 1-2 day settlement  
**Implication:** Asgaya's 1% fee + same-day settlement is 80% cheaper

### 2. BCH Volatility (±20% Monthly)
**Source:** Historical price data 2020-2026  
**Finding:** 7% buffer covers 90% of daily swings  
**Implication:** Sellers lose money on <10% of transactions

### 3. Merchant Retention (Triple-Dip Model)
**Source:** Economic modeling + merchant interviews  
**Finding:** 0.5% spread + product margins = 21-42% total return  
**Implication:** Merchants stay active 6+ months, vs 2-3 months without triple-dip

### 4. AnyHedge Stability (H€/HAu Tokens)
**Source:** Testnet experiments with €3K pool  
**Finding:** 30-day cycles, auto-renewing, 99% uptime  
**Implication:** Merchant stability layer viable in Phase 0

### 5. Spain → Venezuela Corridor (€50M Annual)
**Source:** Spanish remittance data, Venezuelan diaspora estimates  
**Finding:** 500K Venezuelans in Spain, €100 average monthly remittance  
**Implication:** Phase 0 addressable market = €50M/year
