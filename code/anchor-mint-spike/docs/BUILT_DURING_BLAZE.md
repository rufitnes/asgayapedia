# Built during BCH BLAZE 2026

**Baseline tag:** `v0-prehackathon-baseline` (2026-11-11)
**Build window:** BCH BLAZE 2026, kickoff 2026-11-14 14:00 UTC, submissions 2026-11-22 14:00 UTC.

This repository is the **pre-BLAZE baseline** of the anchor-mint spike: a browser dapp that connects through WizardConnect, has the wallet sign a genesis anchor NFT, and verifies it on chipnet. It is the working proof behind the BLAZE identity anchor.

The BLAZE slice (Mercar Asgaya) is built in the competition repository from 14 Nov. This baseline stays frozen for comparison.

```bash
npm install
npm test
```

Public documentation: [asgayapedia](https://github.com/rufitnes/asgayapedia).
