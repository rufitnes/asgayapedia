## Overview

Phase 0 is an experiment to validate core assumptions. These are the questions we don't have answers to yet:

1. **Will the 7% buffer hold in real-world usage?**
2. **Do merchants adopt stability tokens (H€/HAu)?**
3. **Can bulletin board scale to 10,000+ listings?**
4. **Is passive mode sticky (12+ month retention)?**
5. **What regulatory response will we face?**

---

## Critical Unknowns

### 1. Volatility Buffer Adequacy
**Question:** Is 7% enough, or do we need 10%?  
**Why it matters:** Sellers lose money if buffer too small  
**How we'll find out:** Phase 0 real-world transactions  
**Mitigation:** Dynamic buffer sizing based on market conditions

### 2. Merchant Stability Preference
**Question:** Do merchants choose H€, HAu, or raw BCH?  
**Why it matters:** Stability layer capital allocation  
**How we'll find out:** Phase 0 merchant onboarding  
**Mitigation:** Offer all three options, track adoption rates

### 3. Bulletin Board Scalability
**Question:** Can NFT indexing handle 10,000+ listings?  
**Why it matters:** System performance at scale  
**How we'll find out:** Stress testing + Phase 0 growth  
**Mitigation:** Optimize indexing, consider Layer 2 scaling

### 4. Trader Retention (Passive Mode)
**Question:** Do traders stay active 12+ months?  
**Why it matters:** Liquidity provider churn kills network  
**How we'll find out:** Phase 0 trader cohort analysis  
**Mitigation:** Improve passive mode UX, add incentives

### 5. Regulatory Risk
**Question:** Will Spain/Venezuela crack down?  
**Why it matters:** Could shut down entire corridor  
**How we'll find out:** Legal counsel + real-world operations  
**Mitigation:** Own-funds model, no custody, legal defense fund
